# Sistem Informasi Administrasi RT

Sistem Informasi Administrasi RT merupakan aplikasi berbasis web yang dikembangkan untuk membantu proses pengelolaan administrasi dan kegiatan warga di lingkungan Rukun Tetangga (RT).

## Teknologi yang Digunakan
- PHP Native
- MySQL
- HTML
- CSS
- JavaScript

## Fitur Aplikasi
- Dashboard Admin
- Dashboard Ketua RT
- Dashboard Warga
- Pengelolaan data warga
- Pengelolaan kegiatan warga
- Pengelolaan keuangan RT
- Pengelolaan administrasi
- Pengelolaan pengaduan
- Integrasi pembayaran Midtrans

## Instalasi
1. Clone repository ini.
2. Pindahkan folder project ke direktori `htdocs` (jika menggunakan XAMPP).
3. Buat database MySQL.
4. Import file database yang tersedia.
5. Sesuaikan konfigurasi database.
6. Jalankan Apache dan MySQL melalui XAMPP.
7. Buka project melalui browser.

## Pengembang
Dikembangkan sebagai project sistem informasi administrasi lingkungan RT.
